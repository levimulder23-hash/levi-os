# amplify-os (pointer)

Amplify's real home is three separate git repos. Open the smallest one for the task:
- Website: `~/Amplify/amplify-website/` — own CLAUDE.md; `site/` is the only active implementation; `docs/status.md` is the design gate.
- Business operations: `~/Amplify/amplify-ops/` — own CLAUDE.md; `context/` is the source of truth for company facts; `workstreams/index.md` for live work; `decisions/log.md` append-only.
- Media: `~/Amplify/amplify-media/`.

Rules: never copy private ops context into public materials; website changes come only through `amplify-ops/workstreams/website-inputs/`. `~/Amplify-Design/` is frozen legacy (prototypes, V4 briefs, an older amplify-os fork) — read-only until the website no longer references it.

Levi's own Amplify notes that don't belong in those repos go here.
